The mission

Get OBS out of hostage hands

OBS Studio is the backbone of live streaming, recording and capture for millions of people. It deserves an open, engineering-led home where a fix is judged by whether it fixes the bug.

OBS-Rust starts from the real OBS codebase and its Git history, and brings Rust into it gradually — replacing the parts that break, keeping the capabilities that make OBS useful.

This began as a patch to fix a crash. Upstream closed the pull request and banned the author from the org, because the fix came from an AI.

That is not a technical standard. So we forked — same source, same licenses, same credit to the OBS contributors — and we publish our work in the open, with the receipts.
