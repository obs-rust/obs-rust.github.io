Drop-in, by contract

Nothing you rely on breaks

The public surface is a compatibility contract. Rust replaces C behind the same symbols, and four tiers of tests keep the two identical.

Clibobs C ABI

The exported symbols and headers stay the same. Plugins compiled for OBS load without a rebuild.

v5obs-websocket

The upstream C++ plugin ships unmodified as the compatibility check. Stream Deck, Touch Portal, bots and overlays keep working.

pyScripting

The Lua and Python scripting APIs and the frontend API work as before. Your scripts and docks still run.

⇄Profiles & scenes

On first start it copies upstream OBS's settings, profiles, scenes and plug-in settings into its own folder. The originals are left untouched.

How it's built

Every port starts red

A port starts with a failing test and is finished when that test passes. Before the C version is deleted, the Rust replacement has to pass all four tiers:

Rust unit tests

Fast, focused tests on the new Rust module itself.

Unchanged C tests

The original cmocka suite, unmodified, run against the Rust implementation.

Differential

The Rust and C versions run side by side on the same inputs, and the outputs are compared.

Black-box protocol

Real obs-websocket clients run against the whole app.
