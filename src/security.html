Security tracker

Vulnerabilities in obs-rust are reported privately, fixed under embargo and shared with the OBS Project in encrypted archives before they are published.

Report a vulnerability Policy Archives ↓

A bug reachable only from trusted local input (your own settings, plugins or scripts) is low risk: open a normal public issue for it. Anything a remote party can reach, or that leaks credentials, goes to a private advisory.

Disclosure archives

Each archive holds one PDF per embargoed advisory, with its proposed fix, for the OBS Project. The zips are public; the password is not: it is kept in README.md of the private repository obs-rust/obs-security-upstream-review, open only to invited reviewers.
